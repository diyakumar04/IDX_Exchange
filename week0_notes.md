# Week 0 - MLS Data Pipeline Orientation Notes 

# Objective 

Objective is to understand how monthly MLS datasets are produced and exported as CSV files for analysis 

# Files Reviewed 

- IDX Exchange Internship Handbook 
- Real Estate Primer 
- Metadata Document 

# Data Source Understanding 

The internship datasets come from CRMLS MLS data and are provided as monthly CSV files: 
- CRMLS Listing: represent properties entered into the MLS 
- CRMLS Sold: represent properties that completed a transaction 

# Local Data Setup 

The raw CSV files are stored locally and not uploaded to GitHub 

Available files currently include datasets from '202401' through '202604'
