# IDX Exchange MLS Analytics Project 

This repository contains my individual project work for the IDX Exchange Data Analyst Internship. 

## Project Objective 

The goal of this project is to clean, prepare, analyze, and visualize MLS real estate listing and sold transaction data using Python and Tableau. 

## Tools

- Python 
- Pandas 
- VS Code
- GitHub
- Tableau Public Desktop

## Data Privacy 

Raw CSV files and source MLS data are not included in this repository. The data is stored locally only and excluded from GitHub. 

## Workflow

This project uses two main data pipelines: 
- Listings pipeline: creates and updates 'listings.csv'
- Sold pipeline: creates and updates 'sold.csv' 

These CSV files will be used to build Tableau dashboards and market intelligence reports.
